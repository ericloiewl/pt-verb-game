# 葡語動詞變位填空 (Portuguese Verb Conjugation Game)

A single-file interactive web game for practicing Portuguese verb conjugations. Fill in the missing conjugated forms and get instant feedback.

## Features

- Clean, responsive single-page UI (no build step required)
- Conjugation fill-in-the-blank exercises
- Immediate correctness feedback

## Usage

Open `verb-game.html` directly in any modern browser — no installation or server needed.

```bash
open verb-game.html
```

## Project Structure

- `verb-game.html` — the complete game (markup, styles, and logic in one file)
- `verb-game-plan.md` — design notes and plan

## Development

This is a static HTML file with no dependencies. To make changes, edit `verb-game.html` and reload the browser.
