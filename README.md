# 葡語動詞變位填空 (Portuguese Verb Conjugation Game)

A single-file interactive web game for practicing Portuguese verb conjugations. Fill in the missing conjugated forms and get instant feedback.

## Features

- Clean, responsive single-page UI (no build step required)
- Conjugation fill-in-the-blank exercises
- Immediate correctness feedback

## Usage

Open `index.html` directly in any modern browser — no installation or server needed.

```bash
open index.html
```

## Project Structure

- `index.html` — the complete game (markup, styles, and logic in one file)
- `verb-data.js` — the `window.VERB_DATA` dataset loaded at runtime

## Development

Static HTML with no dependencies. To make changes, edit `index.html` or `verb-data.js` and reload the browser.
